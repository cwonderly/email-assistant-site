Privacy Policy

Effective November 7, 2026

Email Assistant is a private tool that runs on one household's Mac. Gmail data stays on that Mac. It is never sold, shared, or sent to any server we run. We don't run any servers.

What Email Assistant accesses

With the account owner's permission (Google sign-in), Email Assistant uses the Gmail API to read:

  • Message details, not message bodies: sender, subject, date, mailing-list and unsubscribe headers, and Gmail's labels and categories (for example "Promotions").
  • Who the account has sent email to, so people the user writes to are never suggested as junk.
  • Gmail's short preview text of delivery-failure notices, only to recognize when an unsubscribe email it sent could not be delivered.

What it changes, and only with approval

Nothing is changed until the user reviews a list of senders and confirms. For the senders they approve, Email Assistant:

  • moves those senders' marketing email to Gmail's Trash. Trash keeps it for 30 days, and it is never permanently deleted by this tool. Order, shipping and account emails are kept;
  • creates Gmail filters so future marketing email from those senders goes to Trash;
  • unsubscribes using the sender's own unsubscribe link. Where the sender only accepts an unsubscribe email, Email Assistant writes it and sends it only after the user approves that specific email;
  • moves delivery-failure notices about its own unsubscribe emails to Trash.

Email Assistant never sends any other email.

Where data is stored

  • Everything is stored only on the user's own Mac: Google sign-in tokens, the list of suggested senders, and progress records. It is kept in a private folder readable only by that Mac user.
  • There are no accounts, servers, databases, analytics, tracking, or advertising.
  • The only network connections are to Google's Gmail API and, when the user approves an unsubscribe, to that sender's unsubscribe link.

Sharing

Gmail data is not sold, shared with, or transferred to anyone. It is not used for advertising, and it is not used to develop, improve, or train artificial intelligence or machine-learning models.

Google API Services User Data Policy

Email Assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

  • Remove Email Assistant's access at any time at myaccount.google.com/permissions.
  • Uninstalling Email Assistant and deleting its folder on the Mac (~/.email-assistant) removes all stored data.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.

Questions

Email Assistant is set up and maintained privately for one household. Questions about this policy go to the person who installed it on your Mac.
